### Portfolio Website

I built and deployed my personal portfolio website using **AWS and Terraform Infrastructure as Code**.

**Live Website:** [portfolio.danushvithiyarth.in](https://portfolio.danushvithiyarth.in)

The portfolio infrastructure demonstrates a secure static website deployment using:

- **Amazon S3** for private static website file storage
- **Amazon CloudFront** as the CDN and public entry point
- **CloudFront Origin Access Control (OAC)** for secure S3 access
- **AWS Certificate Manager (ACM)** for HTTPS
- **Amazon Route 53** for DNS and custom domain routing
- **Terraform** for automated infrastructure provisioning and file uploads
- **S3 bucket versioning** and secure bucket policies

This project shows practical experience with **AWS cloud infrastructure, Terraform, DNS, HTTPS, CDN configuration, private S3 origins, and secure static website hosting**.
